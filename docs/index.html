The Architecture

The LLM Never Watches the Video. It Reads It.

Naive video agents dump 30,000 frames into an LLM context (45M tokens of noise). video-use reduces an hour of footage into 12KB of structured speech text + on-demand visual composites.

L1

Layer 1 — Audio Transcript (Always Loaded)

One ElevenLabs Scribe call gives word-level timestamps, speaker diarization, and audio events like (laughter) and (applause). All takes pack into a compact takes_packed.md.

## C0103 (duration: 43.0s, 8 phrases)
  [002.52-005.36] S0 Ninety percent of what a web agent does is wasted.
  [006.08-006.74] S0 We fixed this.
L2

Layer 2 — Visual Composite (On Demand)

video-use timeline-view produces a filmstrip + waveform + word labels PNG for any target time range. Called only at decision points — ambiguous pauses, retake comparisons, or cut validation.

$ video-use timeline-view take.mp4 42.0 48.0 -o verify.png
extracting 10 frames from 42.00s to 48.00s
saved: "verify.png" (190 KB)
CLI Suite

Single Native Binary Architecture

No Python interpreters, no virtualenvs, no dependency drift. One fast binary compiled directly for macOS, Linux, and Windows.

SPEECH RECOGNITION

transcribe & batch

Extracts 16kHz mono audio via ffmpeg, checks peak dBFS to prevent uploading digital silence (< -60 dBFS), and sends multipart requests to ElevenLabs Scribe. 

video-use transcribe video.mp4 \
  --audio-track 0

video-use transcribe-batch ./takes/ \
  --workers 4
PROMPT CONDENSATION

pack-transcripts

Walks Scribe JSON files and emits takes_packed.md, breaking phrases on silences ≥ 0.5s or speaker shifts. 

video-use pack-transcripts \
  --edit-dir ./edit \
  --silence-threshold 0.5
COLOR GRADING

grade

Presets (subtle, neutral_punch, warm_cinematic) or data-driven auto mode via ffmpeg signalstats. 

video-use grade clip.mp4 \
  -o graded.mp4 --preset subtle

video-use grade --analyze clip.mp4
CUT & COMPOSE

render

Per-segment extract with 30ms audio fades, lossless concat, overlay timing sync, subtitles last, and two-pass loudness norm. 

video-use render edl.json \
  -o final.mp4 --build-subtitles

video-use render edl.json \
  -o preview.mp4 --preview
VISUAL INSPECTION

timeline-view

Filmstrip + waveform composite PNG for checking ambiguous pauses, retakes, and cut-point sanity without dumping full frames. 

video-use timeline-view \
  clip.mp4 12.0 16.5 \
  --n-frames 10

Correctness Mandates

Production-Correctness Rules

These rules are baked directly into the Rust implementation. Deviation produces broken audio pops, hidden captions, or degraded encodes.

01

Subtitles Applied LAST

Subtitles are rendered after all animation overlays in the filter chain so captions are never occluded.

02

Per-Segment Extract → Lossless Concat

Uses ffmpeg concat demuxer (-c copy) instead of a monolithic filtergraph to avoid double-encoding.

03

30ms Audio Fades at Every Boundary

Bakes afade=t=in:st=0:d=0.03,afade=t=out... into every segment to eliminate audible cut pops.

04

PTS-Shifted Overlays

Overlays apply setpts=PTS-STARTPTS+T/TB so frame 0 lands precisely at the window start.

05

Output-Timeline Subtitle Offsets

out_time = word.start - seg_start + seg_offset ensures captions stay in sync across concatenated takes.

06

Social-Ready Loudness Normalization

Targeting -14 LUFS integrated, -1 dBTP peak, and LRA 11 via two-pass loudnorm.

Questions & Answers

Frequently Asked Questions

Everything you need to know about video-use-rs, AI video editing, and production deployment.

What is video-use-rs? ↓

video-use-rs is a high-performance Rust port of browser-use/video-use. It allows developers and autonomous AI coding agents (Claude Code, Codex, Antigravity) to edit videos conversationally by reading word-level transcripts, detecting silence gaps, auto-grading color, and rendering frame-accurate video with ffmpeg.

How does an LLM edit video without watching every frame? ↓

Instead of passing tens of thousands of video frames into an LLM context (costing tens of millions of tokens), video-use-rs provides a structured 12KB phrase-level transcript with exact word timestamps and silence boundaries. The agent only requests visual timeline composites on demand at specific decision points.

Why was video-use ported to Rust? ↓

The original Python scripts required complex environments (requests, librosa, matplotlib, pillow, numpy). The Rust port packages all functionality into a single standalone binary and embeddable crate with parallel Rayon workers, instant execution, zero runtime dependencies, and memory safety.

Does video-use-rs re-encode entire videos during cuts? ↓

No. video-use-rs follows Hard Rule 2: it extracts only the specified cut ranges with 30ms anti-pop audio fades and color grading, and then combines them using ffmpeg's lossless concat demuxer (-c copy), ensuring maximum speed and visual fidelity.
